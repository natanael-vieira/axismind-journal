# Política de segurança

## Versões suportadas

Apenas a versão publicada a partir da branch `main` recebe correções de segurança.

## Como relatar uma vulnerabilidade

Não publique detalhes de vulnerabilidades em uma issue. Envie o relato para
`natnaelsales@gmail.com`, incluindo uma descrição objetiva, os passos mínimos
para reproduzir e o impacto observado.

Não inclua senhas, tokens, chaves privadas, dados médicos ou outros dados
pessoais no relato. O recebimento será confirmado assim que possível e a
correção será coordenada antes da divulgação pública.
