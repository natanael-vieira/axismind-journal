# Contribuindo com o site do axismind

## Mensagens de commit

Este repositório adota Conventional Commits no formato:

```text
tipo(escopo): descrição objetiva em português
```

Exemplos:

```text
feat(site): adiciona seção de segurança
fix(como-usar): corrige exibição da jornada no celular
refactor(ui): centraliza componentes dos cartões
docs(legal): atualiza informações públicas
test(rotas): cobre páginas institucionais
perf(imagens): reduz o peso das capturas da loja
build(pages): ajusta a publicação no GitHub Pages
```

Use `feat`, `fix`, `refactor`, `docs`, `test`, `perf`, `build`, `ci`, `chore`, `style` ou `revert`. O conteúdo entre parênteses é o escopo afetado; não use parênteses vazios. A descrição pode ser escrita em português.
